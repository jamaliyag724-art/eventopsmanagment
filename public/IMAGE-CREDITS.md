# Utsav image assets

The dashboard event cards and public-site image showcase use bundled local WebP assets. They do not require third-party image hosts.

- `utsav-navratri-garba.webp` — original image generated for this Utsav project.
- `utsav-diwali-leadership.webp` — original image generated for this Utsav project.
- `utsav-conference.webp`, `utsav-wedding.webp`, `utsav-exhibition.webp`, and `utsav-festival.webp` — optimized WebP derivatives of the corresponding image assets already included in this project. The festival-stage image is also used for the College Festival demo card to keep the image local and fast-loading.
- `utsav-venue.webp` — optimized derivative of the project's existing event-venue/gala image.

WebP files were generated locally from these project assets. The older JPEG source files remain in the project for compatibility, but current Utsav event and public-site image mappings use the WebP files.
